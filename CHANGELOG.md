# Changelog

All notable changes to the **Elaris** extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-10-07

### Added
- **Elaris**: Initial release of the clean light theme designed for focused daylight coding.
- **Color System**:
  - Calibrated light surface hierarchy (`#F7F8FA`, `#FFFFFF`, `#F3F5F8`, `#F1F3F6`, `#EEF1F5`).
  - Restrained iris purple (`#5B4BDB`) and cerulean cyan (`#1687C8`) primary accents.
- **Workbench UI**:
  - Complete coverage across editor, sidebar, activity bar, status bar, panels, command palette, tabs, breadcrumbs, and diff editors.
  - Subtle borders and elevation layers without harsh visual outlines.
- **Syntax Highlighting**:
  - High-readability semantic hierarchy for TypeScript, JavaScript, Python, Go, Rust, Java, C/C++, HTML, CSS, JSON, Markdown, and Shell.
  - Tuned contrast for daytime and well-lit office environments.
- **Integrated Terminal**:
  - Clean light terminal surface with tuned 16-color ANSI palette.

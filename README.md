# 🤍 Elaris — A VS Code Theme

> *Where daylight meets deep thought.*

### What is Elaris?

Elaris is a clean, bright Visual Studio Code theme engineered for focused daylight coding.

Instead of blinding white voids or washed-out pastels, Elaris relies on open, layered surfaces, gentle gray boundaries, and an intentional typographic hierarchy. It provides a crisp, comfortable workspace that feels natural in bright rooms, morning routines, and sunlit offices.

### Why You'll Like It

- **Airy surface layers** — Four subtle tiers of light surfaces create clear visual separation without harsh, distracting borders.
- **Calm, precise syntax** — Thoughtfully weighted colors highlight functions, types, and keywords without noisy rainbow clutter.
- **Comfortable daylight contrast** — Dark charcoal text on soft white and cool-gray surfaces keeps code readable without tiring your eyes.
- **Integrated workbench chrome** — The editor, sidebar, tabs, terminal, Git diffs, and menus share a single unified aesthetic.
- **Zero visual friction** — Unnecessary borders and heavy accents are removed so your attention stays on the logic you are writing.

### How to Install and Use

Elaris is an open-source project hosted directly on GitHub. You can package and install it locally in two minutes:

```bash
# 1. Clone the repository
git clone https://github.com/Henilt31/elaris-vscode.git
cd elaris-vscode

# 2. Package the extension
npx @vscode/vsce package

# 3. Install into VS Code
code --install-extension elaris-theme-0.1.0.vsix
```

Once installed:

1. Open Visual Studio Code.
2. Press `Ctrl + Shift + P` (or `Cmd + Shift + P` on macOS) to open the Command Palette.
3. Type **Preferences: Color Theme** and press `Enter`.
4. Select **Elaris**.
5. Start coding.

### The Idea Behind Elaris

A great light theme should feel as natural as reading ink on fresh paper. It shouldn't overwhelm you with stark glare or sacrifice contrast for aesthetics. Elaris was created to give daylight development the same level of care, depth, and restraint that developers expect from premium dark environments.

### Built Around

- Layered soft-white, cool-gray, and subtle slate surfaces
- Focused iris purple and cerulean cyan primary guidance
- Sharp semantic syntax colors tuned for high legibility
- Integrated light terminal palette with balanced ANSI colors
- Readable, muted comments that provide context without getting in the way
